## Independent Problem-Solving Example

### Problem

The dataset showed **class imbalance**, with the *Non-ESG* category representing a large portion of the dataset while *Business Model & Innovation* appeared much less frequently.

### Independent Analysis (without AI)

After reviewing the class distribution and classification reports, I identified that minority classes were more difficult for the model to predict accurately. This indicated that the model could become biased toward the majority class if imbalance was not addressed.

### Implementation (with AI assistance)

After identifying the issue independently, I used AI to help implement a class weighting solution in Logistic Regression:

```python
LogisticRegression(class_weight="balanced")
```

### Result

Applying class weighting improved the model’s ability to detect smaller ESG classes and produced more balanced performance across categories.
