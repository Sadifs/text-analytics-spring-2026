# Overview

This project builds and evaluates supervised machine learning models to classify ESG-related sentences into their corresponding sustainability categories.

The goal is to compare multiple text representation methods and classification algorithms to determine which approach performs best for domain-specific ESG text classification.

Task type: **Multiclass Text Classification**

---

# Dataset

Dataset: **SASB-Aligned ESG Sentences**

Source:  
https://www.kaggle.com/datasets/edwardjunprung/sasb-aligned-esg-sentences

Dataset size: ~6,500 sentences

Target variable: **Parent Label (ESG category)**

Classes:

- Non-ESG
- Environment
- Human Capital
- Social Capital
- Business Model & Innovation
- Leadership & Governance

The dataset contains sentences extracted from corporate sustainability and ESG reports.
